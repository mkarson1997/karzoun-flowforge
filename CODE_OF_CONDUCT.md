# Code of Conduct

FlowForge is an engineering community. Participation should make the project easier to use, understand, review, and improve.

## Expected behavior

- Discuss ideas and code without attacking people.
- Give technical criticism with enough context to be actionable.
- Assume good faith while still requiring evidence for technical claims.
- Respect different experience levels, backgrounds, and communication styles.
- Keep issues and pull requests focused on the project.
- Do not publish private information, credentials, exploits, or vulnerability details irresponsibly.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized conduct, deliberate humiliation, spam, impersonation, doxxing, and repeated disruption are not accepted in project spaces.

## Enforcement

Repository maintainers may edit or remove content, close or lock discussions, reject contributions, or restrict participation when behavior damages the project or its community. Serious security concerns should be handled through the process in `SECURITY.md` rather than public disclosure.

When reporting conduct problems, provide enough context for maintainers to evaluate the incident fairly.
